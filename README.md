## 🌍 Overview

**EarthSonic** is an interactive web platform and psychoacoustic synthesizer that transforms empirical NASA Earth science data into real-time soundscapes and responsive spectrogram visualizations. 

Instead of treating climate indicators merely as silent numbers on static charts, EarthSonic renders the physical dynamics of our changing planet audibly through a deterministic data-to-sound transformation pipeline.

```
+------------------+       +-------------------+       +--------------------+       +----------------------+
|  NASA POWER API  | ----> |  DATA ANALYSIS    | ----> |   SONIFICATION     | ----> | REAL-TIME SYNTHESIS  |
| Satellite Models |       | Normalization &   |       | Mapping Algorithm  |       | Web Audio API +      |
| & Assimilations  |       | Climate Statistics|       | Acoustic Encoding  |       | Dynamic Visualizer   |
+------------------+       +-------------------+       +--------------------+       +----------------------+
```

## 🎯 The Challenge & Problem

### The Problem
Planetary Earth science telemetry—encompassing temperatures, wind shear, shortwave solar radiation, precipitation flux, and atmospheric relative humidity—is typically communicated through complex 2D charts and data tables. While rich in information, these representations can be emotionally detached, visually overwhelming, and inaccessible to visually impaired researchers, students, and citizens.

### The Solution
EarthSonic introduces an **Information Jukebox for Earth**:
- **Hear Climate Cycles:** Day-night shifts, seasonal cooling/warming, rainfall bursts, and atmospheric density variations are perceived naturally through human auditory pitch perception, rhythmic tempo, timbre, and filter resonances.
- **Empirical Fidelity:** Unlike generative background noise or arbitrary loops, **every sound wave generated by EarthSonic is directly calculated from real NASA measurements**.
- **Dual Representation:** Audio and visual representations operate in complete synchrony: the real-time FFT spectrogram and waveform canvas reflect the exact audio frequencies being produced.

## 🚀 Key Features

1. **Direct NASA POWER API Integration**
   - Live daily point telemetry retrieval from `https://power.larc.nasa.gov/api/temporal/daily/point`.
   - Assimilates 7 NASA meteorological parameters: `T2M`, `T2M_MAX`, `T2M_MIN`, `WS10M`, `PRECTOTCORR`, `RH2M`, and `ALLSKY_SFC_SW_DWN`.
   - Cleans missing values (`-999.0` fill values) and performs scientific range normalization `[0.0, 1.0]`.

2. **Real-time Web Audio API Hybrid Synthesizer**
   - Multi-oscillator synthesis engine generating melodic, harmonic, and noise layers directly in the browser.
   - Compliant with modern browser autoplay policies (resumes seamlessly on user interaction).
   - Dynamic biquad atmospheric low-pass filtering simulating sound absorption through moist air.

3. **Live Spectrogram & Oscilloscope Visualizer**
   - High-performance HTML5 Canvas powered by an `AnalyserNode` (`fftSize = 512`).
   - Switchable modes: **Frequency Bars**, **Oscilloscope Waveform**, and **Hybrid View**.
   - Peak frequency tracking, pitch telemetry readout in Hertz (Hz), and filter cutoff diagnostics.

4. **Curated Benchmark Climate Zones & Global Map**
   - Instant presets representing diverse planetary biomes:
     - **Tashkent (Uzbekistan):** Continental Steppe / high seasonal thermal amplitude.
     - **New York (USA):** Coastal Metropolis / storm front transitions.
     - **Tokyo (Japan):** Pacific Coastal / humid subtropical monsoon seasons.
     - **London (UK):** Temperate Oceanic / frequent light precipitations and cloud cover.
     - **Sahara (North Africa):** Hyper-Arid Desert / peak solar irradiance and near-zero moisture.
     - **Amazon (South America):** Tropical Rainforest / intense humidity and convective downpours.
     - **Arctic (Svalbard):** Polar Tundra / extreme thermal sensitivity and seasonal darkness.
   - Interactive Leaflet + OpenStreetMap engine enabling coordinate selection anywhere across the globe.

5. **Recharts Timeline Analysis**
   - Interactive area charts with custom gradients for Temperature, Wind, Solar Radiation, Precipitation, and Humidity.
   - Automated statistical indicators: **Mean**, **Min**, **Max**, and **Regression Trend Direction (Slope)**.
   - Real-time animated audio playhead synchronized with acoustic playback.

6. **Dedicated Hackathon Judge "START DEMO" Flow**
   - One-click presentation mode pre-calibrated to Tashkent across a 30-day temporal window.
   - Guides the user through: **Location → NASA Data Sync → Sonification Engine → Live Visualizer → Timeline Charts**.

## 🎼 The Sonification Algorithm

The core mapping algorithm translates physical planetary units into acoustic synthesis parameters deterministically:

| NASA Parameter | Parameter Code | Physical Meaning | Acoustic Target | Mapping Formula | Audible Effect |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Temperature** | `T2M` | Air Temp at 2m (°C) | **Pitch / Frequency** | $f = f_{min} \cdot \left(\frac{f_{max}}{f_{min}}\right)^{\text{norm\_temp}}$ | Higher temp = higher pitch (130 Hz - 660 Hz). Warming elevates melodic frequency. |
| **Wind Speed** | `WS10M` | Wind at 10m (m/s) | **Rhythm & Tremolo** | $\text{Rate} = 0.5 + (\text{norm\_wind} \cdot 7.5)\text{ Hz}$ | Faster wind = faster pulse cadence and rapid kinetic LFO tremolo flutter. |
| **Solar Radiation** | `ALLSKY_SFC_SW_DWN` | Downward Shortwave (kWh/m²/day) | **Brightness / Overtones** | $\text{Harmonics} = 1 + \lfloor\text{norm\_solar} \cdot 6\rfloor$ | Higher radiation excites FM modulation index, generating crystalline high partials. |
| **Precipitation** | `PRECTOTCORR` | Precipitation (mm/day) | **Rain Percussion** | $\text{Drops/sec} = \text{norm\_precip} \cdot 40$ | Rainfall triggers organic droplet pings and band-passed noise burst transients. |
| **Humidity** | `RH2M` | Relative Humidity (%) | **Low-Pass Filter** | $\text{Cutoff} = 4800 - (\text{norm\_humidity} \cdot 4300)\text{ Hz}$ | High humidity absorbs high frequencies into a dense muffled drone; dry air is crisp. |

## ⚙️ Installation & Setup (Windows)

### Prerequisites
- Node.js (v18+)
- Python (v3.11+)

### 1. Clone or Open Workspace
```powershell
cd C:\Users\Hp\Desktop\fayzik
```

### 2. Backend Setup
```powershell
# Navigate to backend directory
cd backend

# Create virtual environment
python -m venv venv

# Activate virtual environment
.\venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Run automated tests to verify installation
pytest tests/ -v

# Start FastAPI backend server
python -m uvicorn main:app --reload --port 8000
```
*The backend API will start at:* `http://localhost:8000`  
*Interactive Swagger docs available at:* `http://localhost:8000/docs`

### 3. Frontend Setup
Open a new PowerShell terminal:
```powershell
# Navigate to frontend directory
cd C:\Users\Hp\Desktop\fayzik\frontend

# Install node dependencies
npm install

# Start Vite development server
npm run dev
```
*The frontend application will start at:* `http://localhost:5173`

## 🏆 Hackathon Demo Presentation Guide (For Judges)

To present the project seamlessly to hackathon judges:

1. **Open the App:** Navigate to `http://localhost:5173` in your browser.
2. **Click "START DEMO" / "START DEMO TOUR":**
   - The application automatically configures **Tashkent** as the primary climate observation zone.
   - Synchronizes 30 days of empirical NASA POWER data.
   - Displays the telemetry pipeline loading state: *Connecting to NASA Data... → Synchronizing Earth Data... → Calculating Acoustic Normalization*.
3. **Inspect the Data Cards & Globe:**
   - Review live metrics for **Temperature (°C)**, **Wind (m/s)**, **Solar Radiation (kWh/m²/day)**, **Rain (mm)**, and **Humidity (%)**.
   - Notice the green **NASA DATA: LIVE** indicator in the header.
4. **Click "PLAY" (or "LISTEN TO EARTH"):**
   - The Web Audio API initiates playback across the timeline.
   - Watch the **Real-Time Spectrogram** in the center panel react instantly to frequency and amplitude changes.
   - Observe the **Timeline Chart** below, where the cyan playhead advances in perfect synchrony with each day's acoustic signature.
5. **Demonstrate Layer Controls:**
   - Toggle individual layers (e.g., mute **Wind Rhythm** or **Rain Percussion** to isolate the melodic **Temperature Pitch**).
   - Adjust the **Playback Speed** (0.5x, 1x, 1.5x, 2x) or use the **Timeline Progress Scrubber** to jump to weather extremes.
6. **Try Another Climate Zone:**
   - Click **Sahara** or **Amazon** in the climate presets to hear dramatic contrasts: the dry, high-pitched solar shimmer of the desert versus the dense, muffled, rain-saturated chords of the rainforest basin!
